# 생성 파이프라인 구성안 — 텍스트·이미지 배치 & 모델 교체 (회의용)

> 2026-10-20 · PM 초안 · 시간·VRAM은 **추정** (L4 실측 후 확정) · 모델 상세 스펙은 `model_selection.md`

## 0. 흐름
`입력` → **[텍스트]** 카피 + 이미지 프롬프트(JSON) → **[이미지]** 글자 없는 이미지 1~N장 → **UI canvas**에서 문구 배치·수정
- 글자는 canvas가 얹음 → 이미지 모델이 한글을 못 그려도 문제없음 → **로컬 이미지 모델 전부 사용 가능**
- 텍스트 출력은 JSON 구조로 고정 (로컬: vLLM/llama.cpp의 JSON 문법 강제, OpenAI: Structured Outputs)

## 1. 작업량
| 작업 | 텍스트 출력 | 이미지 |
|---|---|---|
| **단일** (인스타·유튜브·카카오) | 헤드라인 3 + 서브카피 + CTA + 프롬프트 → **~300토큰** | 1장 |
| **상세페이지** (커머스) | 5섹션(대표·특징×3·마무리) × (제목 + 본문 2줄 + 프롬프트) → **~1,000토큰** | **5장** |

## 2. 구성 3안
| | **A. 전부 VM** | **B. VM 텍스트 + OpenAI 이미지** | **C. OpenAI 텍스트 + VM 이미지** |
|---|---|---|---|
| 상주 (24GB) | Qwen3-8B + klein 4B ≈ **18GB** | Gemma 4 26B-A4B ≈ **16GB** (GPU는 텍스트 전용) | klein 4B + Z-Image ≈ **22GB** |
| 단일 소요 | ~10~13초 | ~12~20초 | **~6~8초** |
| 상세 5장 | ~40~50초 (GPU에서 순차 처리) | **~30~35초** (이미지 병렬 생성) | ~30~35초 |
| 비용/건 | 0 | 단일 ~$0.013 · 상세 ~$0.07 (medium) | 텍스트만, 1센트 미만 |
| $30로 | 무제한 | 단일 ~2,000건 · 상세 ~400건 | 사실상 무제한 |
| 강점 | 비용 0, "배포" 시연에 최적 | 이미지 품질 최고, 참고 사진 편집 가능, GPU 메모리 여유 | 가장 빠름 |
| 약점 | 상세페이지가 느림, 텍스트·이미지가 GPU를 나눠 씀 | 비용이 쓴 만큼 늘어남, OpenAI 장애 시 이미지 생성 불가 | 문구 품질이 OpenAI에 묶임, 로컬 LLM 시연 없음 |

⭐ **권장: A + B 혼합** — 텍스트는 VM(Qwen3-8B 또는 Gemma 4 12B), 이미지는 UI에서 **[로컬 klein (기본, 무료) ↔ OpenAI Flare (고품질·참고 사진)]** 교체
- 상주: 텍스트 ~6~7GB + klein ~8.5GB + 활성 ~3.5GB ≈ **18~19GB ✓**
- Fallback: VM 텍스트가 바쁘면 Luna로, 로컬 이미지가 바쁘면 Flare로 넘김

## 3. 텍스트 모델 (새 작업량 기준, L4·Q4)
| 모델 | VRAM | 속도 | 단일 300토큰 | 상세 1,000토큰 | 맞는 구성 |
|---|---|---|---|---|---|
| Gemma 4 E4B | ~4.5GB | ~55 tok/s | ~6초 | ~18초 | A (메모리 여유) |
| Qwen3-8B | ~6GB | ~35 tok/s | ~9초 | ~30초 | A · 혼합 |
| Gemma 4 12B | ~7GB | ~25 tok/s | ~12초 | ~40초 | 혼합 (품질 우선) |
| **Gemma 4 26B-A4B** (MoE) | ~14GB | ~45 tok/s | ~7초 | ~22초 | **B** (GPU를 텍스트에 전부 쓸 때) |
| GPT-5.6 Luna | — | 빠름 | ~2~4초 | ~8~15초 | C · fallback |

→ 상세페이지는 어느 구성이든 **30초 이상** → **섹션 단위로 결과를 흘려보내야 함** (텍스트 스트리밍 → 섹션별 이미지 생성 → UI가 섹션을 채워 나감). 현재 API는 동기 응답 → 비동기 응답(202) + 진행 조회 필요.

## 4. UI에서 이미지 모델 교체
| 규칙 | 내용 |
|---|---|
| 선택지 | **상주 중인 로컬 모델 + OpenAI만** 노출. 생성 중 모델 교체(언로드·로드)는 금지: 30~60초 동안 모든 사용자의 GPU가 멈춤 |
| 교체 = 이미지만 다시 생성 | 저장된 `image_prompt`를 재사용(`parent_id` + `model`) → **텍스트는 다시 안 만듦**, 이미지 시간만 걸림 |
| canvas 유지 | 배경 이미지만 바꾸고 텍스트 레이어·위치는 그대로. 크기는 목적별로 고정 (16의 배수로 맞춤) |
| 상세페이지 | **섹션 단위 교체** (예: 3번 섹션만 OpenAI로 다시 생성) |
| 프롬프트 | 모델과 상관없이 쓰는 영어 자연어 문장, **75단어 이하** (SDXL은 77토큰을 넘으면 잘림 → SDXL은 제외 검토) |
| 비교 보기 (선택) | 같은 프롬프트로 2개 모델 결과를 나란히 표시. 비용·시간 2배 |
